# Lemmicorns
A Lemmings-like game for js13kgames jam 2026 "Unicorns and Rainbows"

## Overview
LEMMICORNS is loveletter to the classic game Lemmings. Built for the JS13k game jam, it fits all gameplay, graphics, and music into a 13KB zipped package.

## Controls: Mouse or Touch (if you are precise)
- use the action-buttons 

## How to Play
- really? Lemmings?
- ok: guide he Lemmicorns to the rainbow 
- dont let them fall too high or touch the bottom of the screen
- use tunnels, explosions and bridges to guide them

## Technical Details
- **Engine**: Custom JavaScript, no frameworks
- **Graphics**: One tiny spritesheet for the Lemmicorns, the rast is procedurally generated
- **Audio**: SoundBox-generated music and SFX (the SFX are in one audiotrack, and splitted into multiple FXlike a Spritesheet)
- **File size**: Under 13KB zipped (JS13k rules)
